# Official Codex subagents documentation excerpts

Fetched 2026-11-11 from https://developers.openai.com/codex/subagents/

These are documentation evidence, not runtime validation.

To define your own custom agents, add standalone TOML files under ~/.codex/agents/ for personal agents or .codex/agents/ for project-scoped agents. Each file defines one custom agent. Custom agents can change model settings and instructions or disable supported capabilities. They inherit the parent’s permissions, provider, and MCP servers; a custom agent file can’t override those settings. Every standalone custom agent file must define: name description developer_instructions If a custom agent file sets model or model_reasoning_effort , the value in the file takes precedence. Before applying the file, Codex resolves each setting from an explicit spawn value, then the corresponding [agents] default, then the parent’s value. If an explicit spawn request or an [agents] default selects a model and neither supplies a reasoning effort, Codex uses that model’s default effort. A custom agent file that sets only model preserves this previously resolved effort. Set model_reasoning_effort in the file too if the selected model doesn’t support that effort or you want a different one. Skills inherit from the parent, and a custom agent can disable individual skills with skills.config . Global settings Global subagent settings still live under [agents] in your configuration . Field Type Required Purpose agents.enabled boolean No Enable or disable multi-agent tools. agents.max_concurrent_threads_per_session number No Cap concurrently open spawned-agent threads, excluding the primary. agents.default_subagent_model string No Set the default model for spawned agents. agents.default_subagent_reasoning_effort string No Set the default reasoning effort for spawned agents. agents.interrupt_message boolean No Record a model-visible message when an agent turn is interrupted. Notes: agents.enabled defaults to true . Set it to false to disable multi-agent tools. When you leave agents.max_concurrent_threads_per_session unset, Codex chooses the default. Existing configurations can keep using agents.max_threads as a legacy alias. Explicit spawn values override agents.default_subagent_model and agents.default_subagent_reasoning_effort . agents.interrupt_message defaults to true . Set it to false to omit the model-visible interruption message from the agent’s context. If a custom agent name matches a built-in agent such as explorer , your custom agent takes precedence.
